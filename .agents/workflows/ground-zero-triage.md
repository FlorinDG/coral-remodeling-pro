## ═══ PARKED WORKSTREAM — GRID-REPLACE (post-ground-zero; do NOT start during stabilization) ═══
**GRID-REPLACE — migrate the grid off `react-datasheet-grid` onto TanStack Table (headless).** (Florin 2026-06-28: "notion grid UI is erratic and buggy — keep the logic, replace the table component.")
**Why:** DataSheetGrid (`react-datasheet-grid@4.11.6`) is the root of a disproportionate share of grid bugs — the positional-cursor-during-reorder (wrong-row overwrite), 3-click title edit, coordinate desync. These are its cursor/edit model, not our logic.
**Measured coupling:** the DATA logic is separable + STAYS (store: GlobalDatabase/GlobalPage, filters, sorts, rollups, formulas, relations, drag-reorder, custom header, VAT lookup, views). What's DSG-coupled and must be rebuilt: the column API — ~78 DSG-specific call sites across `NotionGrid.tsx` + `hooks/useGridColumns.tsx` + ~10 `columns/*` components (each is a DSG `Column` with `component`/`copyValue`/`pasteValue`/`disableKeys`), plus the cell editing/selection/keyboard integration.
**Target = TanStack Table (headless):** renders nothing itself → keep the exact Notion aesthetic + custom cells, no license; and WE own the cursor/edit model (where DSG fails). Existing cell components become TanStack cell renderers. (Alternatives: Glide Data Grid — canvas, great for scale, cells are drawn; AG Grid — batteries-included but heavy/licensed/enterprise look. TanStack fits a bespoke Notion grid best.)
**PHASED (each step testable, behind a feature flag; NOT big-bang):**
- **GRID-REPLACE-1** — `NotionGridV2` on TanStack behind a flag: ONE database, text columns, store wiring (read/edit/persist by id, no DSG). Prove the edit model is stable (single-click edit, no reorder-during-edit corruption).
- **GRID-REPLACE-2** — port column TYPES to TanStack renderers one at a time: title, select, date, currency, checkbox, relation, rollup, formula, variants, meta-date → parity with `columns/*`.
- **GRID-REPLACE-3** — port FEATURES: filters, sorts, drag column reorder, sticky custom header, row selection, keyboard nav, copy/paste, VAT lookup, accountant date range.
- **GRID-REPLACE-4** — full parity on 2+ databases; flip the flag; regression-test every view.
- **GRID-REPLACE-5** — remove `react-datasheet-grid` + all DSG code; delete the flag.
